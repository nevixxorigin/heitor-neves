# Portfólio — Editor de Vídeo

React + Vite. Sem dependências extras.

## Rodar
    npm install
    npm run dev      # desenvolvimento
    npm run build    # gera a pasta dist/ para publicar (Vercel, Netlify, etc.)

## O que editar
- `src/config/site.js` — NOME, WHATSAPP_NUMBER (ex.: "5533999999999"), INSTAGRAM_URL
- `src/data/projects.js` — os vídeos (links do YouTube), títulos, descrições e lista de serviços
- `src/App.css` — cores e fontes no topo do arquivo (`:root`)
- `public/logo.png` — monograma usado como logo e favicon (troque o arquivo mantendo o nome)
